## 已实现

| 功能 | 实际行为与边界 |
| --- | --- |
| 发送缓冲 | 默认 10 秒，可关闭或选择 5/10/20/30 秒；持久保存后才开始倒计时，支持撤销、立即发送、恢复原草稿。重启后的缓冲任务暂停待确认，提交结果未知不自动重发 |
| 稍后处理、未回复提醒 | 稍后邮件仅从收件箱隐藏，其他列表显示时间标记；侧栏管理、提前恢复和改时间。未回复判定核对真实邮件头和完整扫描覆盖，无法核对则保留待核对。需应用运行，POP3 不支持，定时发送暂不能同时设置跟进 |
| 保存搜索 | 保存范围、条件和排序；支持无关键词筛选和相对日期。固定来源失效要求修复，不擅自扩展范围；沿用搜索覆盖说明 |
| 附件中心 | 按账户、文件夹及条件查看已索引附件；分批整理本地缓存、查看进度或取消；图片和 macOS PDF 预览，其他格式显示下载/默认应用入口。未批量下载邮箱附件 |
| 快速回复、折叠写信 | 阅读区内回复，与完整窗口共用一个编辑会话；折叠保留草稿，换信先持久保存，恢复不覆盖另一封正在编辑的邮件。隐藏编辑器不响应发送快捷键 |
| 轻量动效 | 面板、反馈和写信窗口的轻量过渡；保持 66px 列表几何、滚动锚点和拖选快照，支持减少动态效果 |

前后端迁移、账户删除、源身份和过期回调均纳入集成；已有定时发送、发送记录、搜索分页和普通阅读快捷键继续复用。

## 子 agent 独立复审

三路交叉评审后复审通过，未发现剩余 P1/P2 阻塞项。主要修复均补回归测试：

- 发送：同一写信会话跨普通/定时入口只允许发布一次；入库失败的孤立 MIME 不阻断安全重试；定时任务及墓碑阻止旧草稿复活。
- 提醒：完成整轮扫描前再次核对各文件夹 UIDVALIDITY；重复或历史回复不错误唤醒；原邮件代际失效不串信。
- 草稿：保存并关闭期间冻结编辑，避免最后输入丢失；本地恢复不强制读取账户凭据；无法恢复的 CID 图片明确失败。
- 账户：账户/凭据删除提交成功后才清理本地任务；失败回滚不丢草稿、缓冲和提醒，清理失败不反报删除失败。
- 搜索/列表：迟到快照不能覆盖新事件；固定范围可正确改回当前文件夹；合并更新保留完整身份的滚动锚点。
- 附件：空范围拒绝查询；分批整理不会重复前 20 封；取消 A 后重启 B，A 的迟到结果不会改坏 B 的按钮与状态。
- 焦点：模态 Tab 限定及关闭后焦点归还；预览和折叠草稿隔离发送快捷键；稍后标记及未读数说明保持一致。

## 实际交互检查

使用独立本机演示服务 `http://127.0.0.1:53606/?open`，全部为模拟账号和邮件，没有向真实邮箱发送邮件：

1. 无关键词、仅“有附件”筛选返回结果及覆盖说明；保存为“含附件的邮件”，侧栏再次打开保持范围。
2. 附件中心列出演示附件，PDF/图片预览可切换；不支持的 XLSX 明确解释并保留外部打开入口。
3. 模拟发送后在 10 秒内撤销；恢复后收件人、主题、正文保留，折叠显示已保存。
4. 草稿折叠时打开附件预览，按 ⌘Enter 不触发发送；Esc 关闭预览并恢复焦点。
5. 稍后处理一小时，在管理视图显示原邮件、账户和时间；提前恢复后移除暂存。

macOS Quick Look 的合成 PDF 预检、进程启动与取消清理由隔离脚本验证，详情在 C/D 证据；浏览器模拟预览不等于已安装 Tauri 应用的系统预览验收。
