# Windows 适配与验收

基线：PR #15 `e3780005e91063b8862f532fb68de7620e24ef4b`。Windows 工作在独立分支 `codex/windows-support`，以 PR #15 为依赖，避免与缓存修复混写。

## 交付范围

Windows x64 NSIS 当前用户安装包，面向 Windows 10/11；保留 IMAP/POP3、发送缓冲、离线缓存、草稿、附件和 macOS 功能。Windows 使用原生标题栏和 Ctrl 快捷键；附件打开方式由系统选择，PDF 暂交给默认应用。凭据继续采用本地 AES-256-GCM，Windows 限制密钥及文件 ACL 为当前用户和 SYSTEM。

通知使用随机本地票据及协议激活，URL 不带邮箱和正文；票据有期限和数量上限，支持启动后定位，保留接收代次和邮箱 UIDVALIDITY。UI 尚未就绪时只保留最后一次点击；账户身份变化不再打开旧引用。

## TDD 与 review

- 存储：Unicode 路径、替换已有文件、替换失败保留原文件、Windows 锁定文件、长路径、精确 ACL、junction/reparse、下载索引父目录链接。
- 界面：Ctrl+Enter 可发送且遵守 IME/忙碌/弹层/折叠保护；平台标签与布局、PDF 外部打开、系统选择器和真实错误反馈、通知冷启动及身份验证。
- 网络/通知：图片下载大小、空响应、HTTP 失败和危险跳转；票据重启恢复、过期/未知/路径注入拒绝、延迟交付及 XML 转义。
- 交付：完整窗口覆盖、PR/手动触发、回写密钥隔离、同版本同 SHA、文件摘要校验、CRLF 版本读取、隔离安装冒烟。

各组先补失败用例再实现，后由其他 subagent 复核。Windows 类型检查、浏览器模拟和本机测试均不替代 Windows 原生运行。

## 验证记录

初轮本地：739 项 JavaScript、537 项 Rust 通过，12 项依赖外部邮箱服务的 Rust 测试忽略；Chrome 模拟 Windows/DPI 9 项通过。后续修复和 CI 的最终结果以本 PR 和补充记录为准。

CI 的 Windows 任务必须通过：前后端测试 → x64 安装包 → 隔离安装 → 主窗口及 WebView2 存活 → 截图/日志 → 卸载。这里无真实邮箱数据，不证明实际邮箱收发和通知中心交互已验收。

需在用户 Windows 桌面继续验收：真实账户收发与离线阅读、系统托盘/开机启动、通知弹窗/通知中心/退出后的邮件跳转、系统应用选择器、PDF 打开、中文输入法与多屏 DPI、版本升级保留账户及待发草稿。未发送真实邮件，未替换用户已安装应用，未手动触发正式发布。
