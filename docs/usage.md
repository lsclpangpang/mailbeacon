# 使用指南

添加邮箱时填写邮箱服务商提供的**授权码**，不是网页登录密码。常见邮箱会自动填写服务器，其他邮箱可手动设置。

## 常用快捷键

下表 `⌘` 在 Windows 对应 `Ctrl`，`⇧` 对应 `Shift`。Windows 使用 `Delete` 删除邮件，`Ctrl+Enter` 发送。

| 按键 | 操作 |
| --- | --- |
| `J` / `K`、`↓` / `↑` | 按列表顺序切换上下封；会话模式下切换会话 |
| `Space` | 先向下滚一屏；到底后优先打开列表后面的未读邮件，没有则打开下一封 |
| `R` / `A` / `F` | 回复 / 全部回复 / 转发 |
| `E` / `S` / `U` | 归档 / 星标 / 标为未读 |
| `⌫` | 删除；废纸篓内彻底删除须确认 |
| `/` 或 `⌘F` | 搜索 |
| `⌘N` | 写邮件 |
| `⇧⌘N` | 收取新邮件 |
| `⌘↩` | 发送 |
| `Esc` | 关闭当前弹层或阅读选择 |
| `Shift+F10` | 打开当前邮件的右键菜单 |

## 读信与整理

侧栏可集中查看所有收件箱、未读、星标、草稿和已发送，也可切到单个邮箱。列表支持未读、红旗、附件和 `@我` 筛选；首次建立搜索索引时先返回已索引的结果，并显示进度。

远程图片默认拦截，可选择「显示图片」或「始终显示此发件人的图片」。双击正文图片可用系统默认程序打开；附件菜单可打开、选择打开方式、保存或在访达 / 文件资源管理器中显示。

右键邮件选择「移动到…」或「下载邮件（.eml）」；下载单封邮件不必先打开，也不会因此标为已读。完整原文含附件，保存在系统「下载」目录。文件以主题命名，同名时增加编号，不覆盖已有文件。

拖动列表与阅读区之间的分隔线可调宽度，双击恢复默认。侧栏收起后，将鼠标移到窗口左侧可临时展开。

## 批量整理与操作结果

列表平时隐藏复选框。点击右上角「更多 → 多选邮件」进入多选模式，再点击整行勾选或取消；也可按住鼠标拖过连续多封，拖到列表边缘会自动滚动。拖动从已选邮件开始时取消这一片选择，范围外的选择保留。

支持 Shift 连选和 ⌘A 全选已加载邮件；方向键或 J/K 移动焦点，Space 或 Enter 勾选当前行。选择不会打开邮件或标记已读，新收到或后来加载的邮件不会自动加入选区。「清空」只取消勾选，「完成」或 Esc 退出多选；切换邮箱、文件夹、筛选或搜索条件时也会退出。

批量栏可标已读/未读、加星、归档、移动或删除。归档使用各邮箱自己的目录；移动到指定文件夹只支持同一邮箱。废纸篓内的永久删除必须单独确认。

结果分别列出成功、失败和待确认数量。失败可重试；待确认先刷新核对。服务器提供可靠移动凭据时，可在 **10 秒内撤销**普通删除、归档或移动；永久删除不能撤销。列表「更多」可查看操作记录。

## 搜索与离线阅读

搜索可选择当前文件夹、当前邮箱或全部邮箱，并组合未读、星标、附件、发件人和日期条件。跨文件夹搜索默认排除垃圾邮件与已删除，可手动包含；结果分页加载。

搜索提示会说明本机覆盖程度和同步时间。已保存的完整正文会补入索引，其他邮件可能只有摘要或正文开头；没有匹配不代表服务器不存在该邮件。搜索不包含附件内容或图片文字。POP3 请在其收件箱单独搜索。

不输入关键词也可只按条件查询。常用条件可保存为侧栏「智能文件夹」，保留范围、排序和相对日期规则；临时调整条件不会自动改写保存内容。原账户或文件夹失效时需修复范围。

IMAP 断网后可读取已保存的文件夹和邮件快照；只有摘要、缓存已清理或外部归档目录不在线时，会说明无法打开的原因。离线副本只读，已有附件可打开，不会标服务器已读、发送回执或排队整理。重新联网刷新后才恢复在线操作。缓存受容量限制，长期保留请使用下载备份。

侧栏「附件」汇总已解析邮件中的附件，支持名称、类型、账户等筛选。「补充本地附件」分批整理已缓存邮件，支持取消，不会全量下载邮箱。选中附件按 Space 快速预览图片；macOS 同时支持 PDF 预览，Windows 的 PDF 面板提供默认应用打开入口。Esc 关闭并返回；其他格式可下载或交给默认应用。

## 稍后处理与跟进

阅读区或邮件右键菜单可设置「稍后处理」。邮件暂时从本机收件箱隐藏，到期恢复；网页邮箱的位置和已读状态不变，其他列表仍可找到并显示时间标记。侧栏可提前恢复、改时间或取消。

写信时可设置未回复提醒。应用依据真实回复邮件头及扫描范围核对；断网或扫描不完整时显示待核对，不把“没查到”当作“对方没回复”。这些提醒仅在本机应用运行时处理，退出期间到期的提醒在下次启动后汇总；POP3 暂不支持，定时发送暂不能同时设置跟进。

## 发送记录与账户修复

侧栏「发送记录」保留普通和定时邮件的发送状态及原文，可查看和导出。**已发送表示发信服务器已接受**，不表示对方已读；副本待同步单独显示，补存副本不会再次发送邮件。结果待确认时先检查记录，手动重新发送须在页面确认，可能产生重复邮件。

普通发送默认等待 **10 秒**，期间可「撤销」或「立即发送」。在「设置 → 邮件发送 → 发送缓冲时间」可选择关闭、5、10、20 或 30 秒，修改后自动保存，仅影响之后新发送的邮件，已排队和定时邮件不变。撤销后可恢复原草稿；已有另一封正在编辑时，会保留独立恢复入口。退出后未开始提交的缓冲任务在下次启动时暂停，需确认发送；已经开始提交的邮件无法撤销。

账户有故障时，点击侧栏错误提示或到「设置 → 邮箱账户 → 连接设置与授权码」。可更新授权码与服务器参数，分别检测收信、发信，再保存或重连；检测不发送测试邮件。授权码留空保持原值。保存设置与连接恢复分别报告，失败时保留表单输入。

更换收信服务器会隔离旧缓存和旧邮件引用，避免相同编号串信；已有导出文件保留。邮箱地址与接收协议不在修复页切换。

## 写信、签名与草稿

写信工具栏支持字体、字号、颜色、列表、对齐、链接、图片和表格。附件可点击选择或拖入窗口，总大小上限 **50 MB**。

回复时上方编辑新内容，下方保留原邮件格式与内嵌图片；普通附件不会自动随回复或转发带出。修改后关闭写信窗口会询问是否保存草稿，发送期间暂时锁定编辑。

阅读区可直接快速回复，也可展开为完整写信窗口或折叠到底部继续读信。切换邮件前会保存当前内容；折叠后的草稿显示原主题，点击可继续编辑。折叠时 ⌘Enter 不会发送该草稿。

| 功能 | 用法 |
| --- | --- |
| 签名 | 在账户设置中填写并点「保存签名」；清空后保存即关闭。新邮件、回复和转发都会带入 |
| 切换发件账号 | 替换尚未修改的自动签名；已经手动修改的内容保留 |
| 草稿 | 编辑时自动保存，优先存服务器草稿箱；离线或 POP3 使用侧栏「本地草稿」 |
| 模板 | 工具栏「模板」可保存主题与正文，不含签名；插入时仅在主题为空时填入模板主题 |

## 定时发送与已读回执

点击「定时」选择发送时间；侧栏「定时发送」可立即发送、改时间，或取消定时并转回草稿。**到点时应用须保持运行，后台运行也可以**；退出期间到点的邮件，会在下次打开时发送。尚未提交时遇到连接失败可重试；如果服务器是否接受无法确认，会停在「需要确认」，不会自动重复发送。

勾选「已读回执」向对方请求回执，对方可以拒绝。收到此类请求时会询问是否发送，**不会自动发送回执**；回执地址与发件人不同时会提示。

## 通知与后台运行

「设置 → 通知与常规」可选择通知内容、免打扰时段、菜单栏图标和开机启动；每个账户可单独关闭提醒，IMAP 还可指定收件箱之外的提醒文件夹。窗口在前台时不弹通知，点击通知可打开对应邮件。

macOS 上关闭主窗口只是隐藏，应用仍会收信。使用「退出 MailBeacon」才会结束运行；自动收信、规则、自动下载和到点发送均需要应用运行。

## 会话、规则与通讯录

**会话**：列表右上角「更多 → 按会话显示」合并往来邮件。阅读区可切换会话中的邮件，包括已发送的回复；只有实际打开且服务器确认的邮件才标为已读。

**收信规则（IMAP）**：侧栏「收信规则」可按发件人、收件人（含抄送）、主题或附件设置条件，执行移动、标为已读、加星标；支持全部条件满足或任意满足。规则按顺序执行，多个移动命中时以第一条为准。

规则只在应用运行时处理新邮件；可点「对收件箱最近 500 封执行」补处理。被规则移出收件箱的邮件不会由自动下载保存；手动移回后不会被规则再次移走。

**通讯录**：支持联系人、分组及 vCard、CSV 导入导出。写信输入名字或地址会联想联系人、分组和最近联系人；选择分组会填入所有成员。最近联系人可用 × 或 `Shift+Delete` 移除。

## 账户设置：缓存与下载

打开「设置」，点击账户标题展开。以下**正文磁盘缓存、下载目录复用、自动下载和全量下载均仅支持 IMAP**，POP3 暂不支持；各账户独立配置。

### 邮件缓存

打开过的邮件原文保存在本机，重启后可复用。默认开启「后台预先缓存收件箱邮件」，从最新邮件开始，读信时暂停；页面可查看占用、封数、进度和错误，并点「立即更新缓存」。

| 设置 | 默认值与范围 |
| --- | --- |
| 缓存总量 | 默认 **2048 MB**，可设 **64～102400 MB** |
| 预先下载的单封上限 | 默认 **5 MB**，可设 **1～32 MB**，只影响后台预先缓存 |

超过总量会淘汰最久未使用的缓存，单封原文超过 **32 MB** 不存磁盘。关闭后台预缓存后，打开过的邮件仍会缓存，也可手动预下载一次。缓存会被清理，长期保留邮件请使用下载归档。

### 复用已下载目录

「已下载的邮件」列出自动下载位置和全量下载目录，显示是否在线。全量下载选过的目录会自动登记，也可点「添加已下载目录…」重新关联**本应用为该账户生成的全量下载目录**。

请保留归档目录中的隐藏索引；任意来源的 `.eml` 文件夹不能直接导入。复用时只读文件、不计入缓存总量；移除目录只停止复用，不删文件。自动下载目录须在自动下载设置中更改。

目录离线、文件无法使用或读取过慢时会回到服务器下载；超过 32 MB 的归档原文也不用于此缓存复用。

### 自动下载新邮件

启用「自动下载新邮件」，选择本地目录并保存后，只归档之后新到收件箱的完整 `.eml`（含附件），不下载历史邮件、不改变已读状态。默认关闭，可查看累计保存数量、最近保存位置和错误原因。

进度跨重启保留，重新打开后补下载退出期间的新邮件；关闭自动下载不删除文件。重新启用、更换目录或有效过滤规则会从新的收件边界开始，不追溯旧邮件。一般错误自动重试，认证失败或服务器重建邮箱时需按提示处理。

### 下载过滤

「不过滤」「白名单：命中才下载」「黑名单：命中则跳过」三选一。匹配方式如下：

| 方式 | 匹配范围 |
| --- | --- |
| 任意命中 | 同一组关键词匹配主题、发件人名称或地址、正文，任意一处命中即可 |
| 按字段设置 | 主题、发送人、收件人、正文分别填写；任意字段命中即可，空字段忽略。收件人按邮件头实际存在的收件人、抄送、密送匹配 |

每行一个关键词，不区分大小写，不匹配附件或 HTML 代码。每种匹配方式最多 **100 个**，字段模式四栏合计 100 个，每个最多 **200 字符**；启用黑白名单至少填一个。切换方式会保留填写内容，仅当前规则生效。手动下载单封邮件不受此过滤限制。

### 全量下载与继续备份

在「下载此账号全部邮件」中选择父目录开始。会归档所有可访问的服务器文件夹，包括收件箱、已发送、草稿、自建文件夹、垃圾邮件、已删除；完整 `.eml` 按账户和文件夹保存，不改变已读状态。同一封信出现在不同文件夹时分别保留副本。

默认不过滤；可勾选「继承该账号的黑白名单规则」，使用**开始时已保存的规则**，即使自动下载关闭也生效。修改规则后应先保存再开始，任务中途更改不会影响本次下载。

任务显示扫描与处理进度、当前文件夹，以及已保存、已有、跳过、失败数量。**100% 表示处理完毕，不保证全部保存成功**，请同时查看结果。内容冲突或失败会保留原文件并报错。

可随时取消，已保存文件保留。关闭设置或收起账户不会停止下载；**退出应用后不会自动重开全量任务**，需手动选择同一父目录，重新扫描核验并跳过相同邮件。本次扫描之后新到的邮件，留待自动下载或下次全量下载处理。

## 授权码迁移与备份

两平台的账户授权码均加密保存在本机，更新应用无需重复授权钥匙串。旧版 macOS 账户首次升级可能请求钥匙串权限；迁移成功后不再访问，失败时设置中显示原因，重启可重试。旧钥匙串条目保留，不会自动删除；新增账户回退到旧版时需重新添加。

| 平台 | 账户与邮件数据目录 |
| --- | --- |
| Windows | `%APPDATA%\com.lsclpangpang.mailbeacon\`（可粘贴到资源管理器地址栏） |
| macOS | `~/Library/Application Support/com.lsclpangpang.mailbeacon/` |

Windows 的数据目录与程序安装目录分开；将程序装到 D 盘不会自动移动账户和缓存。邮件下载与备份目录可在账户设置中另选。从旧 macOS 标识 `com.lsclpangpang.mailpulse` 升级时，首次启动会自动迁移邮箱数据和界面偏好，保留旧目录；步骤与故障处理见[应用标识迁移](app-identity-migration.md)。

备份或迁移前先**退出应用**，完整复制当前数据目录，保留配套的 `local.db` 数据库和 `secrets/credentials.key` 密钥。只备份数据库无法恢复授权码；密钥丢失或损坏时，应恢复整套配套备份。另行保存的邮件归档目录及其隐藏索引也需一起备份。

本地加密可保护单独泄露的数据库；拥有相同用户权限的软件如果同时取得数据库和密钥，仍能解密，保护边界低于系统钥匙串。请将完整备份当作敏感资料保管。
